## Global sections (`/admin/global-sections`)

Area: design. Module: Core. Supports versions, duplicate, quick edit (name).

| Field | Type | Tab | Help |

## Redirects (`/admin/redirects`)

Send visitors from an old address to a new one.

Area: seo. Module: Core. Supports duplicate, quick edit (from, to, active), CSV export, CSV import matched on from.

| Field | Type | Tab | Help |
| --- | --- | --- | --- |
| From (`from`) | text, required | Content | The old address, starting with /. For "starts with" and "pattern" matches this is the prefix or the regular expression. |
| To (`to`) | text, required | Content | Where visitors go instead. A path on this site or a full address. |
| Type (`code`) | select, required | Content | 301 passes search ranking to the new address. 302 is for short-term moves. 410 tells search engines the page is gone for good. |
| Match (`match`) | segmented, required | Content | Exact matches one address. Starts with moves a whole section. Pattern uses a regular expression for advanced cases. |
| On (`active`) | switch | Content | Switch off to pause this redirect without deleting it. |
| Times used (`hits`) | number | Content | How many visitors this redirect has sent on. |
