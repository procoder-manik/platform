## Cards (`cards`)

Services, features, steps, quotes or prices in any card design. Group: Cards and lists. Module: Core.

| Field | Type | Help |
| --- | --- | --- |
| Heading (`heading`) | text | The section heading. Leave empty for none. |
| Intro (`intro`) | textarea | A short line under the heading. |
| Card design (`template`) | select, required | How each card looks. Every design uses your brand colours and fonts. |
| Card (`items`) | repeater | The cards in order. Each template uses the fields that fit it and ignores the rest. |
| Title (`items[].title`) | text | Card heading, or the person’s name on testimonial and team cards. |
| Text (`items[].body`) | textarea | A short description, or the quote on testimonial cards. |
| Image (`items[].image`) | image | Used by image, editorial, product, team and testimonial cards. |
| Icon (`items[].icon`) | icon | An icon name, used by service and glow cards. |
| Big number (`items[].number`) | text | Used by big number cards, for example "120+". |
| Role or caption (`items[].role`) | text | Job title on team and testimonial cards, or a small caption. |
| Price (`items[].price`) | text | Shown as written, for example "$499" or "From ৳15,000". |
| Price period (`items[].period`) | text | For example "per month". Leave empty for one-time prices. |
| Included (`items[].features`) | tags | What a price card includes, one item per tag. |
| Badge (`items[].badge`) | text | A small label such as "Popular". |
| Link (`items[].href`) | url | Makes the card a link. |
| Link text (`items[].linkLabel`) | text | Button text on price and product cards, for example "Choose plan". |
| Card HTML (`customHtml`) | code, administrators only | Your own card markup. Use {{title}}, {{body}}, {{image}}, {{link}} and {{price}}. Scripts are removed. |
| Card CSS (`customCss`) | code, administrators only | Styles for your card. They only apply inside this block. |
| Layout (`layoutMode`) | segmented | A grid shows every card. A carousel slides them sideways. |
| Cards per row (`columns`) | segmented | On desktops. Phones always show one card per row. |
| Slide automatically (`autoplay`) | switch | Pauses on hover and when the visitor prefers reduced motion. |
| Seconds between slides (`interval`) | number | From 2 to 30 seconds. |
| Show arrows (`arrows`) | switch | Previous and next buttons. |
| Show dots (`dots`) | switch | One dot per card, to jump to it. |

## Presets

- **Blueprint** (`blueprint`): Deep navy and signal blue, the original look.
- **Clean** (`clean`): White, black and one accent. Quiet and sharp.
- **Warm** (`warm`): Cream and terracotta with a friendly serif.
- **Bold** (`bold`): High contrast and large type that stands out.
- **Calm** (`calm`): Soft greens and plenty of space.
